# 🛒 E-Commerce Sales Dashboard | Power BI

An interactive E-Commerce Sales Dashboard created using Power BI to analyze sales performance, monthly trends, country-wise revenue, and product-level details.

## 📊 Dashboard Preview

![E-Commerce Sales Dashboard](dashboard.png)

## 🔎 Project Overview

This project transforms raw e-commerce data into an interactive dashboard that helps understand sales performance and purchasing patterns.

The dataset was cleaned and prepared using Python (Pandas) in Google Colab before being imported into Power BI for visualization.

## 📌 Key Metrics

- 💰 Total Sales: 4.25M
- 🧾 Total Invoices: 12.38K
- 📦 Total Quantity: 2M

## 📈 Dashboard Insights

- Sales performance across different countries
- Monthly sales trends
- Average quantity sold by month
- Country-wise sales contribution
- Product-level sales details
- Interactive country filtering
- Cross-filtering between visualizations

## 🛠️ Tools Used

- Power BI
- Python
- Pandas
- Google Colab
- Microsoft Excel

## 🧹 Data Preparation

The raw dataset was processed using Pandas to clean and prepare the data for Power BI analysis.
